# EntitleFlow — Codebase Reference

This folder contains structured analysis of the codebase patterns, conventions, and architecture. It exists so that future sessions can quickly load context without re-reading every file.

**When to use:** Read the relevant file(s) here before making changes. Only go back to source code if the reference seems stale or the task requires deep context.

**When to update:** After any major structural change (new tables, new patterns, new conventions), update the relevant reference file.

## Files

| File | Purpose |
|------|---------|
| `architecture.md` | High-level system architecture, tech stack, deployment |
| `api-patterns.md` | API route conventions, auth patterns, error handling |
| `component-patterns.md` | React component conventions, styling tokens, page structure |
| `database-schema.md` | All tables, columns, enums, relationships |
| `file-tree.md` | Key directories and what lives where |
| `design-tokens.md` | Colors, typography, spacing, component styling rules |
| `type-system.md` | TypeScript types, enums, label/color maps |
| `active-sprint.md` | Current implementation status and what's been built |

## Issues Found

### ⚠️ WARNING — Webhook Endpoint Conditionally Unauthenticated

**File:** `app/api/email/inbound/route.ts`  
**Severity:** Warning  
**Description:** The inbound email webhook only enforces the `INBOUND_EMAIL_SECRET` token check if that environment variable is set. If `INBOUND_EMAIL_SECRET` is absent from the Vercel environment, the endpoint accepts POST requests from anyone without authentication and will attempt to process them as inbound emails, inserting records into the database via the admin client.

```ts
const secret = process.env.INBOUND_EMAIL_SECRET;
if (secret) {  // ← skips auth entirely if env var is missing
  // token check
}
```

**Recommendation:** Change the guard to fail-closed — if `INBOUND_EMAIL_SECRET` is not set, return 401 rather than proceeding. Also verify in Vercel dashboard that this env var is configured in production.

**Proposed fix:**
```ts
const secret = process.env.INBOUND_EMAIL_SECRET;
if (!secret) {
  return NextResponse.json({ error: 'Webhook secret not configured' }, { status: 401 });
}
const headerToken = request.headers.get('x-webhook-secret');
const queryToken = request.nextUrl.searchParams.get('secret');
if (headerToken !== secret && queryToken !== secret) {
  return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
}
```

⚖ Dual Scoring Pathway

AI Pre-Score (FlowE)

FlowE's Proposal Reviewer agent analyzes each section against the selected rubric and funder preferences. Outputs section-level scores, gap analysis, and specific improvement suggestions. Runs in seconds — gives teams immediate feedback before human review.

Human Review Score

Team members score using the same rubric with written comments and discussion threads. Supports multiple reviewers with consensus scoring. Combines with AI score into a weighted composite with confidence interval and submission readiness indicator.

🔬 Scoring Methodology Sources

NIH Simplified Framework (2025)

3 factors: Importance of Research, Rigor & Feasibility, Expertise & Resources. 1-9 scale with binary sufficiency gates. Adapted for nonprofit proposals.

NSF Merit Review

Intellectual Merit + Broader Impacts + Commercial Potential. Binary rating per criterion. Adapted to Community Impact + Organizational Merit.

Foundation Standard

Weighted rubric matrix used by community foundations. Criteria x Weight = Score. 4-point scale (Excellent/Good/Adequate/Poor). Fully configurable.
